## あなたのペットに迎える

1. [若葉くらげをダウンロード](https://github.com/kitschgang/Mypet_for_GPT/raw/refs/heads/main/leaf-jellyfish.zip)して、ZIPファイルを展開してください。
2. 展開した **`leaf-jellyfish` フォルダー全体**を、次の場所に入れてください。

   | OS | 保存先 |
   | --- | --- |
   | macOS | `~/.codex/pets/` |
   | Windows | `%USERPROFILE%\.codex\pets\` |

   `pets` フォルダーがなければ作成してください。`CODEX_HOME` を別の場所に設定している場合は、その中の `pets` フォルダーを使ってください。

3. アプリで **Settings（設定）→ Pets → Refresh（更新）** を開き、**새싹 해파리**（若葉くらげ）を選んでください。ペットの表示名は現在、韓国語になっています。
4. チャットの入力欄に `/pet` と入力すると、ペットの表示・非表示を切り替えられます。

一覧にすぐ表示されない場合は、アプリを開き直して確認してください。

### Pythonでインストールする

Python 3があれば、このリポジトリの **Code → Download ZIP** から全ファイルをダウンロードし、展開したフォルダーで次のコマンドを実行する方法もあります。追加パッケージは不要です。

```sh
python3 install.py
```

Windowsでは `py install.py` も使えます。同じ名前のペットフォルダーがすでにある場合は、上書きせずに停止します。

## どんな動きをするの？

| 状態 | 動き |
| --- | --- |
| 待機 | 静かに呼吸して、まばたき |
| 右・左へ移動 | 触手を揺らしながら泳ぐ |
| あいさつ | 触手を上げてごあいさつ |
| ジャンプ | ぴょんと跳ねて戻る |
| エラー | ちょっとしょんぼりしてから元気に |
| 入力待ち | 首をかしげて、こちらの返事を待つ |
| 作業中 | 集中しながら触手を動かす |
| レビュー | じっくり確認して、まばたき |

9種類の状態、合計57フレームでできています。背景が透明な1536 × 1872ピクセルのWebP画像で、1コマのサイズは192 × 208ピクセルです。

## ファイルについて

- `leaf-jellyfish.zip`：手動インストール用のペットフォルダー
- `pet.json`、`spritesheet.webp`：ペットの設定と、9種類の動きを収めた元ファイル
- `preview-*.gif`：動きのプレビュー
- `character.png`：元のキャラクター画像
- `install.py`：ローカルのペットフォルダーにコピーする、任意のインストールツール
- `SHA256SUMS`：ペットファイルを確認するためのチェックサム

キャラクターとアニメーションの画像は、OpenAIの画像生成ツールで制作しました。その後、フレームの配置・背景の透明化・動きを確認しています。OpenAIの公式キャラクターではありません。

ペット機能やメニュー名は、アプリのバージョンによって異なる場合があります。[公式ペットガイド](https://learn.chatgpt.com/docs/pets)もご確認ください。
